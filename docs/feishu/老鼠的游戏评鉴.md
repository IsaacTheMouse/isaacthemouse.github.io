# 写在前面
**这并不是一篇游戏推荐**，而是一篇评论总集。

在这篇文章里，我会按**对我的影响程度**来举例一些我觉得值得了解的游戏。因为是按照我的看法来排序，所以会**非常主观**，不过也能勉强当作一个游戏推荐来看。我并**不保证文章里提及的游戏适合所有人**，所以如果你对其中某个游戏感兴趣了，记得提前查一查有关信息或者直接来问我，我会提供更多内容。

在挑选游戏时，我尽量避免了那些**人尽皆知的游戏**在重复的项目里出现，这样能使这份清单能够涵盖更多内容。

译名大部分非官方，标注价格为国区，同组排名不分先后。

# 唯一性
对我来说无法被替代的作品。

![](1e2237e77f5e6f896edb6bdaf06323ac.png)

**见证者 / The Witness**

Steam￥112 史低 ￥22

2021 年的一天，我像往常一样打开了一个新的游戏。静态的模型，高饱和度的颜色，稍微有些让人 3D 眩晕的视角，第一眼看起来似乎是个不怎么起眼的走路模拟型解谜游戏。但很快这个游戏就给我带来了无法用语言形容的震撼，在我用第一个小时大概理解了游戏玩法和周围的区域之后，我像被漩涡卷入一般无法克制地全身心投入了游玩中。事实证明，是的，我完全没有办法停止游玩。我花了一个**完全没有停顿的 24 小时的时间**把这个游戏的普通结局路线玩到了通关，在睡了一觉之后又把留声机挑战的全成就做完了。在通关之后，我坐在电脑屏幕前面，看着它又一次把我踹到桌面，我想：

**我这辈子都玩不到像这样的游戏了。**

我很难向一个没有玩过这款游戏的人解释它对我的影响，甚至有时候即使对方玩过也不一定能做到。对我来说，见证者就像是游戏设计的圣经，真正带给我敬畏的东西。吹哥的设计哲学在迷茫的我眼里就像一阵春风，扫清了所有的迷雾，他指着电子游戏设计最珍贵的宝珠告诉我，答案就在那里。

![](a2e4bdf60419aa6d47f4eae0e1411480.jpeg)

**我的世界 / Minecraft**

标准版￥89 豪华版 ￥119

开发：Notch

音乐：C418

玩家：我

*移除了Herobrine

# 独特的
即使在自己的品类里也是最独特的那一个，对我造成了某方面的深刻影响。

![](4b17c823ae7a58c65a1e68e1076dc0e1.jpeg)

**超阈限空间 / Superliminal**

Steam￥70 史低 ￥28

“如梦似幻的体验”说的就是这个游戏，从头到尾打一次通关就像做了一场梦。作者**对于玩家心理的把控**已臻至化境，不管是谜题场景设计还是剧情都十分流畅舒适且恰到好处，让玩家在达到那个“点”之后总能感到意料之外情理之中。再加上配乐等加分项，就成为了一部10/10的完美作品。

![](2ea2db308ead93d49425fd9367b3ad52.png)

**新手指南 / The Beginner's Guide**

Steam￥36 史低 ￥10

我心目中**叙事游戏**的巅峰，没有之一。所有往玩家操作框架里塞小说的RPG都应该跪下来仰望的作品。只有亲自游玩才能感受到的剧情温度，细腻的情感表达和大胆的剧情设计一同出现，但只通过**电子游戏独有的手法**展现，不管是场景设计抑或是旁白，甚至连令人不适的、刻意的剧情设计都是有意为之，真正贯彻了“作者”与“玩家”交流的神作。

以防你不知道，这个游戏的作者还有另一款作品，叫**史丹利的寓言**。

![](2061866b496436d204fd656bf2942e67.jpeg)

**无限宫苑 / Manifold Garden**

Steam￥76 史低 ￥30.4

巧妙利用分形的概念拓展了无限的空间，同时在这点上很好地驾驭住了高维场景的设计可能性，再加上独特的美术风格、优秀的音乐设计和恰到好处的谜题难度，就成就了一部带有些许禅意的视听盛宴。玩这游戏真的很有一种逛博物馆的美感。

在这个游戏身上我看到了**电子游戏的可能性**：现实中无法实现的非欧空间、多方向重力、高维空间，在程序的编排下呈现在了我的屏幕上。

顺带一提我真的很喜欢这部作品的OST，非常好听的同时还非常适配游戏的整体风格，有能力的话可以去买来听一听。

![](dfcd3d12b7010d4d5d8346bce625333a.png)

**传送门 2 / Portal 2**

Steam￥42 史低 ￥3

经典中的经典，简单规则导出优秀谜题设计的**教科书**，以及顶级的剧情世界观场景美术。我真的真的很喜欢没有人类的废土世界观。

值得一提的是，传送门的设计非常**符合人类的直觉**，这在某种意义上来说降低了学习成本。

![](2cd33d6fc49e4a4c4b85a5a74c770fd8.png)

**环绕走廊 / Antichamber**

Steam￥68 史低 ￥13

讲这个游戏之前不得不提它的发售日期：2013年2月1日

作为**精神前作**启发了不少作品，你能在Manifold Garden、The Talos Principle甚至Superliminal等游戏里看到它的影子：哲理性的思考，刻意的地图设计，以及对玩家心理的操纵。

真正的导师。

![](69151f7b37aae1d5a77d9676a82ab880.png)

**汤姆克兰西的彩虹六号：围攻 / Tom Clancy's Rainbow Six Siege**

标准版 Steam￥88 史低 ￥22

可能在这个基本全是独立游戏的榜单里看到这么一款标准的**多人线上竞技**会让你感到一些困惑，但事实是我确实很喜欢彩虹六。它的竞技节奏很快，对思维回路的速度要求很高，虽然学习成本也很高，但我阴差阳错地打了几百小时休闲所以轻车熟路了也。虽然现在这游戏还在转型的阵痛期，玩家质量也参差不齐，但中国选手挺进邀请赛大舞台已经够让我高兴了。感觉还能再玩两年。

![](1a4b695125a28cd40bb148d95d8cc7c4.jpeg)

**以撒的结合 / The Binding of Isaac**

重生本体 Steam￥48 史低 ￥24

我想聊的不是作为新世代肉鸽标杆的它。实际上以撒最吸引我的点是它对圣经的**文化再创作**，以一个离异家庭孩子的视角呈现了西方文化中这本最重要典籍的影响，作者从一本书拓展出了一整个世界的功力不得不让人叹服。

同时这也让我思考，我们从本土文化到游戏艺术的创作，到底是哪一步出了问题？

![](f96256df99bcd9d8afebb45941a62384.png)

**一次机会 / OneShot**

Steam￥42 史低 ￥14.4

在我看来，OneShot最独特的游戏设计莫过于它对于**“玩家角色”**的处理。在这个游戏里，玩家不再像传统RPG游戏一样“扮演”角色，相反的，它要求玩家去做自己。这种重新思考玩家位置的设计使得主要角色不再是一个被操控的符号，更像是一个朋友，一个同路人。再加上质量颇高的剧情脚本，Niko就成了一个游戏史上留名的生动活泼的角色。我是说，很难有玩家在玩过这部作品之后不喜欢上这样一个可爱善良的小孩子，不是吗？

![](92daed6239daba4e34790ce1efb3c39d.png)

**传说之下 / Undertale**

Steam￥36 史低 ￥10

我觉得以它的热度，应该不需要我做推荐了吧？虽然有点小鬼，但它确实是我的 metagame 启蒙。优秀的角色设计与剧情编排，用多结局设计来隐藏作者真正想要传达的思想与情感，是，太多太多的文章和视频已经讲过一遍又一遍。那对于我来说，什么才是独特的，真正影响我的呢？我想大概是游戏之外的**社区创作**。虽然有着诸如低龄化、内容质量等问题，但 16 17 年左右的它对第一次接触如此庞大社区的我来说无疑是十分震撼的。贴吧里或是本土创作或是搬运翻译的那些AU二创简直就是打开了一扇扇新世界的大门，让我流连其间。



#### 有趣的
即使白金通关后仍时常会想起，有趣的游戏设计令人印象深刻。

![](fa0b57b811b9aa8977334ff493e294ab.png)

**看看者 / The Looker**

Steam for Free

**我这辈子都玩不到像这样的游戏了。**

事实证明我是错的，在 22 年年中群友提及之后，我就迅速下载熬油了这部恶搞版见证者。从标题到玩法无处不见的致敬，又毫不掩饰地对见证者做着解构。作者把自己的思想**包装成对设计的否定**，诙谐的同时又引人思考。整部作品充斥着一种互联网时代青年人的恶趣味，令人忍俊不禁。

![](fb2573d941dec1baf1dff4e6c9c3e021.jpeg)

**太极 / Taiji**

Steam￥80 史低 ￥48

事实再次证明我是错的，又一款**见证者的致敬游戏**。从这些“高质量”致敬游戏也能看得出见证者对解谜游戏这个分类的影响之深。

相比 The Looker 的恶搞，太极就显得正经多了。虽然并不是使用一笔画的谜题设计，但又处处有着见证者的影子。优雅的引导和不下见证者的谜题质量让它即使独立出来看也是一部解谜游戏的上乘之作。

![](f4f7ea783b2156f56ab9ef564ca6cffa.jpeg)

**密码 / Cypher**

Steam￥22 史低 ￥6

它不太像是个游戏，更像是个**密码学博物馆**。

引用小黑盒用户florencia的评价：一个很专业的密码学介绍及教学游戏，很考究很全面，就算对于一个小白，能把迷题当例题学明白就已经对应用广泛的密码学入门了。

我没能写出来多少，只做了一章多一点就歇逼了，真太难了。

![](81c9b1abd63194a538c5e28ee7356539.jpeg)

**文字游戏 / 《文字遊戲》**

Steam￥48 史低 ￥38.4

非常有趣的**中文方块字谜题**设计，游戏只有中文（笑）。

中期一部分谜题显得重复且拖沓，另一部分则是有些无厘头，可以看得出作者驾驭谜题设计有些困难。看评论区也能看得出来，不管是剧情节奏把控亦或是谜题设计作者都有点搞砸了，可惜了这么好的底子，不过也还好你底子不错。

似乎有一个真结局的设定，我还没玩完，线索不是很明显，可能需要看一下攻略。

![](ebf2701fbca15ef612018cc58ffa8699.jpeg)

**画中世界 / Gorogoa**

Steam￥58 史低 ￥17.4

和致命框架、纪念碑谷一起作为我的早期**游戏艺术启蒙**。这几作的特点都是谜题简单，玩法非常符合直觉，画面表现优秀且美术风格独特吸睛，一言以蔽之就是门槛低。它们可能不能给你带来思考，但它们的存在本身就**代表着一种艺术**。

![](92ec428482be673d540918ca56910387.png)

**锈湖系列 / Rusty Lake Series**

系列游戏，包括Cube Escape系列、Rusty Lake系列以及部分散作。

游戏本身是比较常见的点击系剧情解谜，值得一提的是游戏外稳定跟随新作产出的**全球层面的ARG**。如果不了解可以B站搜索“零崎人物”观看相关视频，部分ARG有国内玩家参与。

![](b1f1f3a54384030632b32faf1a9c454f.jpeg)

**塔罗斯法则 / The Talos Principle**

Steam￥108 史低 ￥10.8

哲学思考与解谜的结合，教科书级别的谜题质量，以及我最喜欢的人类灭绝型废土世界观。

探讨的哲学问题是**人之所以为人**，稍显深奥，但还是很有趣。我很喜欢里面的语音记录，让冰冷的问题带上了人的温度。

最近刚出了第二部，不管是画质还是谜题种类都有很大的进步，可以算得上是3A解谜游戏了（草）。

![](9c216d4c00bccd71402892418f55e82c.jpeg)

**Baba是你 / Baba Is You**

Steam￥50 史低 ￥35

非常烧脑的逻辑解谜，非常巧妙的关卡设计。

唯一的缺点就是**太难了**。

**真的好难。**

![](3a57797b206c089fcba9b6baf9d6bead.jpeg)

**风之旅人 / Journey**

Steam￥58 史低 ￥23.2

经典作品，不需要我太多介绍，只是想到总有人不熟悉所以放上来。

在优美风景间的探索，氛围感十足的音乐（但是他们不卖OST！），以及，跨越所有人类间隔阂的交流。我不知道陈星汉是怎么想出这么天才的主意的，但是当你不用语言就能和屏幕另一端的那个不知道谁心意相通时，你会发自内心的笑出来。

**“相逢何必曾相识”**

![](dc0b7e7c68cba507d94228a91ae2dbe2.jpeg)

**巴别塔圣歌 / Chants of Sennaar**

Steam￥80 史低 ￥64

它可能不是第一个做语言学解谜的，但它是做得最好的。经过精细设计的语言不像地书那样直白，但又确实符合语言学的造字规律。巧妙化用巴别塔的典故架设世界观，多语言设计让游玩不显得单调。再加上独特的美术风格和高质量的音乐，就成就了这款不可多得的佳作。

再如果从推理游戏（侦探游戏）的角度分析，就能看出制作组如何在迷题难度上进行了精雕细琢——光是一本笔记本，就让我通关整个游戏几乎没有遇到卡关。在信息归纳和验证上，我看到了奥伯拉丁的回归等一系列优秀侦探游戏的影子。

最后感谢你能够看到这里，稍微多聊两句吧。你或许会发现整篇文章都很少提及**剧情**这两个字，是的，我并不是很喜欢在讨论游戏时谈到剧情内容。这涉及我对游戏，或者更严谨的来说，电子游戏的看法。

首先我必须澄清，我并非什么极端的玩法党或是反剧情党，我并不会对游戏里现成的优秀剧情视而不见。但我个人非常反对**不对故事进行处理，强行往游戏里塞入小说剧情**的行为。我认为电子游戏作为一种新的艺术类型，应该有自己独特的叙事手段。就像电影的镜头、雕塑建筑等没有文字的表达一样，电子游戏也应当能做到**不需要文字的叙事**。所以我心目中存在这样一种究极游戏模板：它不存在现实中的语言文字，不管哪个国家什么语言的玩家都能明白规则、理解玩法，并且在其中获得乐趣。我知道这很苛刻，并且看起来只有解谜游戏等弱剧情游戏才能实现，但我相信在将来，这肯定会成为一定程度上的一个标准。
